# Report tab sizing and retained QA layout

## Reproduction and cause

The relay report action kept its top-level window at `about:blank` and placed
the HTML inside a sandboxed iframe. Chrome can persist a separate zoom setting
for that blank URL. With a synthetic Chrome profile configured at 175% for
`about:blank`, the original opening rendered the report at devicePixelRatio
1.75 and a CSS viewport of 823 pixels in a 1440-pixel window. The report's CSS
still declared the same 14-pixel body text as the older CLI template.

The viewer now navigates the reserved tab to a standalone blob document. This
retains the report's CSS instead of compensating with CSS zoom, transformed
content, or changes to the user's browser preferences. The embedded report
continues to use `sandbox="allow-scripts allow-downloads"`, without
`allow-same-origin`, and the viewer has no opener. Report and viewer blob URLs
are released when the tab closes or opening fails. Downloads retain their
existing filenames and attachment behavior; lost relay data still triggers
one read retry.

## The previous layout fixes are separate from zoom

The active local QA agent `relampo-order-cadence` embeds the older report:
its seven overview cards wrap after six columns and its execution details
use an auto-fit grid. The backend integration already includes the RLP-800
layout fixes: one overview row, five detail cards in one row, drag zoom and
Reset without the redundant Zoom button. Updating the editor alone cannot
change HTML generated by that older agent. An updated agent binary is
prepared separately; existing saved reports are not silently rewritten.

## Verification

- The opening, download, error, cleanup and lost-frame unit tests pass.
- Editor validation passes typecheck, lint, 166 test files / 1602 tests, and build.
- Chrome smoke uses a temporary profile and the actual AgentFileLink component,
  with synthetic API responses generated by the CLI's HTML reporter.
- Both Local and Distributed match the standalone saved CLI HTML: 14-pixel
  body text, 30-pixel heading, 13-pixel table text, and a 1280-pixel wrapper in
  the 1440-pixel test window. Seven overview cards occupy one row; five detail
  cards occupy one row; the redundant Zoom button is absent.
- The report script runs, cannot access its parent document, and its viewer
  has no opener. Browser smoke reports no page errors.

No user Chrome preferences, AWS credentials, live run, or recording is changed
by these tests. Deployment and the live-agent restart are separate activation
steps.
